# 💼 Business & Workplace English Pro (Repository 8 / Variety 8)

Automated video generator for **Executive Communication, Workplace Emails & Meeting Diplomatic Phrasing** in 9:16 vertical reels.

## 🌟 Key Features
- **Executive Slate Design**: Clean corporate typography and contrast cards.
- **Casual vs Diplomatic Formula**: Replaces blunt demands with polite, persuasive corporate formulas.
- **Practical Workplace Context**: Teaches learners how to handle deadlines, disagreements, and executive presentations.
- **High-Monetization Demographic**: Appeals to ambitious working professionals worldwide.

## 🚀 How to Run
```bash
# 1. Generate business reel
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/business_english_reel.mp4 output/run_XXXX/metadata.json
```

- **Target Audience**: Corporate employees, managers, and remote professionals working in international teams.
